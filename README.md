# Star Hit Cafe — kr4-js-shop

Учебный интернет-магазин кафе Star Hit Cafe. Контрольная работа №4 по дисциплине «Фронтенд и бэкенд разработка».

## Основа проекта

Проект `kr4-js-shop` создан на основе адаптивного HTML/CSS-интернет-магазина из контрольной работы №3 (`kr3-responsive-shop`).


## Структура JavaScript-файлов

- `data.js` — массив товаров `products` (10 позиций, единая структура: `id`, `title`, `category`, `price`, `discountPercent`, `rating`, `isAvailable`, `image`, `description`, `specs`).
- `catalog.js` — каталог: состояние, поиск, фильтрация по категории, сортировка, пагинация, рендер карточек через `createElement`, корзина, избранное, счётчики, пустое состояние, делегирование событий.
- `product.js` — страница товара по параметру `?id=`: заполнение заголовка, изображения, описания, рейтинга, статуса, цены со скидкой, таблицы характеристик и кнопки добавления в корзину.
- `cart.js` — корзина на странице заказа: вывод позиций, изменение количества, удаление, подсчёт подытога через `reduce`, скидка по промокоду, сохранение в `localStorage`.
- `validation.js` — валидация формы заказа и формы обратной связи: имя, e-mail, телефон с маской, выбор товара, согласие, вывод ошибок рядом с полями.
- `modal.js` — модальное окно товара на странице каталога: открытие через `showModal()`, заполнение через `textContent`, закрытие по кнопке, клику по фону и клавише Escape, возврат фокуса.
- `index.js` — рендер популярных товаров на главной странице из общего массива `data.js`.
- `theme.js` — переключение тёмной темы с сохранением выбора в `localStorage`.
- `main.js` — общая инициализация: меню-бургер и карусель на главной странице.

## Реализованная логика

- карточки товаров генерируются через JavaScript и `document.createElement()`;
- текстовые данные выводятся через `textContent`;
- реализован поиск по названию товара;
- реализована фильтрация по категории (горячие напитки, холодные напитки, десерты);
- реализована сортировка по цене, названию и рейтингу;
- реализована пагинация каталога;
- реализовано пустое состояние каталога;
- реализована базовая валидация формы заявки и формы обратной связи;
- ошибки и успешные сообщения выводятся на страницу, без `alert()`;
- обработчики событий подключены через `addEventListener()`;
- использованы `querySelector`, `createElement`, `textContent`, `classList`, `append`.

## Самостоятельные доработки

- корзина с добавлением, изменением количества и удалением товаров;
- расчёт суммы корзины через `reduce`;
- промокод со скидкой (`STAR10`, `HIT20`, `CAFE15`);
- избранное с отдельным состоянием и счётчиком;
- сохранение корзины, избранного и темы в `localStorage`;
- пагинация каталога;
- счётчик товаров в корзине и избранном;
- пустое состояние каталога;
- имитация отправки формы без сетевого запроса;
- тёмная тема с сохранением выбора;
- улучшенная карточка товара: рейтинг, бейдж скидки, старая и новая цена, статус наличия, кнопка избранного;
- модальное окно товара с характеристиками и добавлением в корзину;
- расширенная валидация формы: имя, e-mail, телефон с маской, выбор товара, согласие на обработку данных.

## Принцип безопасного вывода данных

Пользовательские данные, данные формы, данные из `localStorage` и данные будущего API не вставляются через `innerHTML`. Для текстового вывода используется `textContent`. Это защищает проект от внедрения HTML-разметки и скриптов через пользовательский ввод.

## Примечание к контрольной работе №4

Реализация по методическим указаниям относится к базовому уровню. Для получения максимального балла за контрольную работу №4 проект расширен самостоятельно: массив товаров увеличен до 10 позиций, добавлены корзина, расчёт суммы, промокод, избранное, `localStorage`, пагинация, тёмная тема, модальное окно товара и расширенная валидация формы.
