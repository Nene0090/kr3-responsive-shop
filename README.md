**Тема:** «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

**Ссылка на опубликованную версию (GitHub Pages):**

## Описание проекта

Проект представляет собой адаптивную версию многостраничного HTML/CSS-сайта интернет-кафе **Star Hit Cafe**. 
Работа выполнена на основе предметной области КР №1, но с использованием чистого CSS (без Bootstrap), подхода Mobile First, современных методов адаптации контента и обеспечением базовой доступности интерфейса.

## Практическая работа №12: Адаптивная вёрстка

На данном этапе была выполнена адаптация сайта под разные размеры экранов.

**Что сделано:**
- Создан отдельный репозиторий `kr3-responsive-shop`.
- Перенесена основа проекта КР №1.
- Создан и подключён отдельный файл `css/responsive.css` (подключается после `style.css`).
- Проверено наличие тега `<meta name="viewport">` на всех страницах.
- Применён подход **Mobile First**: базовые стили написаны для мобильных устройств, расширения добавляются через медиазапросы `@media (min-width: ...)`.
- **Адаптирована навигация:** на мобильных устройствах меню выстраивается в колонку, на планшетах и ПК — в строку.
- **Адаптирован Hero-блок:** на мобильных устройствах элементы идут друг под другом, на ПК — в две колонки.
- **Адаптирована сетка карточек:** используется CSS Grid. На мобильных — 1 колонка, на планшетах — 2, на ПК — 3.
- **Адаптирован каталог:** на мобильных фильтры стоят над товарами, на ПК — сбоку (Flexbox).
- **Адаптивные изображения:** добавлено правило `max-width: 100%; height: auto;`.
- **Адаптирована форма заявки:** на мобильных поля идут в одну колонку, на планшетах и ПК — в две (`grid-template-columns`).
- **Адаптирована таблица характеристик:** обернута в контейнер `.table-wrapper` с горизонтальной прокруткой (`overflow-x: auto`), чтобы не ломать ширину страницы.
- Проверены ширины: 360px, 430px, 768px, 1024px, 1440px.

## Практическая работа №13: A11y-аудит и доступность

На данном этапе была проведена проверка доступности интерфейса и исправлены найденные проблемы.

**Что сделано:**
- **Семантическая структура:** на каждой странице используется один `<h1>`, заголовки идут в логичном порядке. Используются семантические теги: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`.
- **Ссылка пропуска (Skip-link):** добавлена ссылка «Перейти к основному содержимому», которая скрыта визуально и появляется при нажатии клавиши `Tab`.
- **Видимый фокус:** добавлен стиль `:focus-visible` для всех интерактивных элементов (ссылок, кнопок, полей ввода). Фокус виден при навигации с клавиатуры.
- **Кнопки и ссылки:** для действий используются `<button>`, для переходов — `<a>`. Интерактивные элементы не сделаны через `<div>`.
- **Изображения:** у всех смысловых изображений прописан осмысленный атрибут `alt`. 
- **Формы и подписи:** каждое поле формы связано с `<label>` через атрибуты `for` и `id`.
- **Модальное окно:** проверено на доступность (закрытие, фокус).

**Lighthouse-аудит:**
- Проверены страницы `index.html`, `catalog.html`, `order.html`.
- Категория проверки: **Accessibility**.
- Отчёт сохранён в папку `lighthouse/` (файл `accessibility-report.png`).

## Самостоятельные доработки (для повышенной оценки)

Помимо базовых требований методички, в проект были добавлены следующие элементы:
- **Шрифт Garamond:** для всего сайта установлен классический шрифт с засечками (`Garamond, Times New Roman, serif`), что придаёт проекту уникальный визуальный стиль.
- **CSS-карусель на главной странице:** реализована карусель изображений (`coffee-4`, `coffee-5`, `coffee-6`) с плавной анимацией (`@keyframes`) без использования JavaScript.
- **Кастомные курсоры:** реализованы через CSS (`cursor: url(...)`). В обычном состоянии — чашка, при наведении на интерактивные элементы — чашка с паром.
- **Единый визуальный стиль:** тёмно-синяя и бирюзовая цветовая гамма, кастомизация таблиц, форм и карточек.
